# Privacy Policy – Stream Grid

_Last updated: 21 September 2026_

## Short version

Stream Grid does not collect, store or transmit any personal data. There are no
servers, no accounts, no analytics and no third parties involved.

## What the extension accesses

**Page content.** A content script runs on pages you visit in order to find the
`<video>` element and measure its size. It applies CSS classes to hide the
layout around the player and stretch it to fill the window. It does not read
page text, form fields, passwords or cookies, and it does not modify anything
besides the styling described here.

**Tabs.** The extension reads the title, address and icon of tabs that contain a
video, so it can list them for you to choose from, and moves the tabs you pick
into their own windows. This information is only used to draw that list and is
never stored beyond the life of the popup.

**Display information.** The extension reads the size and working area of your
connected monitors in order to calculate where to position the tiled windows.

## What is stored

The following settings are stored locally in your browser using
`chrome.storage.local`, and never leave your device:

- the interface language you selected
- the layout you last used
- the window overlap value
- whether the "cover taskbar" option is on
- which windows are currently tiled, so they can be restored

You can remove all of it by uninstalling the extension.

## What is not done

- No data is sent to any server.
- No data is sold or shared with third parties.
- No analytics, telemetry, tracking or advertising.
- No remote code is loaded or executed.
- Your browsing history is not read, recorded or transmitted.
