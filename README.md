# Stream Grid

A browser extension that puts video into a window with no tab bar or address
bar, stretches it across the whole window, and tiles those windows across a
monitor. Built for watching several live streams at once.

The tab is moved into the new window rather than reloaded, so the stream keeps
playing and you stay logged in.

## Privacy

Stream Grid does not collect, store or transmit any data. There are no servers,
no accounts and no analytics.
